# Ayr-k-matematik-3.-hafta-devi
Ayrık matematik 3. hafta ödevi

Soru 1: 1²+...+n² = n(n+1)(2n+1)/6 ispatı tümevarımla yapılır. n=1 için sağlanır. n=k için kabul edilip n=k+1 için düzenlendiğinde eşitlik elde edilir. 
Soru 2: xy çift ise x veya y çifttir. İkisi de tek kabul edilirse çarpımları tek çıkarak çelişki yaratır.
Soru 3: Karşıt tersi: n tekse n² tektir (2k+1'in karesi tek çıkar). Dolayısıyla n² çiftse n çifttir.
Soru 4: n tek ise n = 2k+1'dir. Karesi 2(2k²+2k)+1 biçiminde yazılarak tek olduğu gösterilir.
Soru5: Ardışık üç sayıdan biri çift diğeri 3'ün katıdır. Çarpımları 2 ve 3 içerdiği için 6'ya tam bölünür.
